# Keep it brief 使用指南

## 适合场景

- 想法很多，需要先理出主线。
- 想先计划，不想马上执行。
- 创建 skill、拆项目、整理功能时容易跑偏。
- 想让 AI 一次只问一个问题。

## 开启方式

直接说：

```text
$keep-it-brief
用 Keep it brief 模式
```

AI 应该回应：

```text
已启用 Keep it brief：我会按计划本推进，一次只问一个问题。
```

## 半自动确认

如果你说：

```text
帮我梳理想法
先做计划
我做到哪里了
记住这个灵感
```

AI 应先问：

```text
你是想进入 Keep it brief 模式，按步骤简短推进吗？
```

## 计划本

AI 会维护：

```text
当前计划：
计划进度：
当前步骤：
下一步：
暂存灵感：
已确认后续计划：
```

## 退出方式

```text
退出 Keep it brief
正常模式
自由发散
不用保持简短
```
