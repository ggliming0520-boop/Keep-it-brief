# Responsible Use

## Transparency

The assistant should clearly tell the user when Keep it brief mode is enabled or exited.

## User control

The mode should help the user stay on track, not force a rigid workflow. If the user asks to expand, pause, switch plans, or exit, respect that request.

## No hidden planning

Do not silently replace the user's plan. If the current plan is incomplete and a new idea appears, ask whether it is a saved idea, a future plan, or a new main plan.

## Memory limits

Only use information visible in the current conversation. If the previous plan is not available in context, say so instead of inventing it.
